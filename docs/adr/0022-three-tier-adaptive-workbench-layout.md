# 工作台采用手机、紧凑宽屏与桌面三层自适应布局

Denova 不再通过单个 `767px` 开关把全部界面切成手机或桌面。手机层使用单主工作面与底部四入口；紧凑宽屏和平板继续使用同一导航语义，但在容器满足最小内容宽度时允许列表与详情双栏，并可把底部导航转换为窄侧栏；桌面层恢复可调整的多栏工作台。

布局层级根据可用容器空间和工作面最小尺寸决定，不以设备名称替代空间判断。旋转屏幕或跨越层级时只能移动稳定内容宿主，不能重建编辑器、Agent 会话或丢失草稿、滚动和选区；粗指针设备在宽屏下仍保持触控尺寸，接入精细指针和键盘后再增强悬停与快捷键。

## Status

accepted

## Considered Options

- 继续二分手机与桌面：实现简单，但平板会在过度简化和拥挤三栏之间跳变。
- 为具体设备建立多套布局：可精细适配，但设备判断脆弱且维护成本持续增长。
- 三层空间驱动布局：边界稳定，并允许各工作面用容器条件渐进增强。
