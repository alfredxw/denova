# 系统任务通知默认关闭并由用户选择开启

应用内任务中心始终是后台任务状态的可靠入口。浏览器或系统通知作为用户级增强偏好提供，默认关闭，只能由用户在设置中明确开启；产品不在首次启动时请求权限。通知仅用于等待用户、失败，以及用户明确订阅的已完成任务。

系统通知必须显示任务类型和来源创作项目，但不能包含敏感正文、提示词或工具内容；点击后按统一项目切换保护恢复对应工作面。HTTPS 不可用、平台不支持或权限被拒绝时，正常退回应用内任务中心，不影响任务执行与恢复。该偏好属于用户配置，不写入创作项目。

## Status

accepted

## Considered Options

- 首次启动请求通知：发现率高，但在用户尚未理解价值时打断并容易被永久拒绝。
- 只使用应用内状态：边界简单，但 PWA 挂起后用户无法及时知道长任务需要处理。
- 应用内默认、系统通知可选：保证基础可靠性，同时让有需要的用户获得后台提醒。
