# 移动端 Agent 使用单会话全屏聊天

移动端 Agent 主工作面一次只呈现当前 Agent 会话的完整聊天，不保留会话侧栏或与正文分屏。顶部标题显示当前会话并可进入独立的全屏会话管理，右侧提供新建会话操作；会话管理支持搜索、切换、重命名和删除，选中后返回聊天并恢复对应草稿与滚动位置。

工具执行、子 Agent 和诊断信息作为消息中的可展开卡片呈现，不占用固定辅助面板。会话与 Agent 定义保持为不同概念：切换会话不会进入 Agents 配置页面。

## Status

accepted

## Considered Options

- 常驻会话侧栏：切换直接，但会持续压缩消息与输入区域。
- 会话下拉菜单：占用少，但搜索、重命名和删除等管理能力难以完整承载。
- 单会话聊天加独立会话管理：当前协作全屏呈现，多会话能力通过明确层级完整保留。
