# 移动端项目工作面以创作结构为默认

写作模式的“项目”工作面使用“大纲、文件、搜索”三个分段，并默认展示按卷、章节和规划文档组织的创作结构，而不是原始文件树。大纲可显示字数、状态或进度；文件分段保留完整目录与高级文件操作；搜索同时覆盖正文、规划文档和资料。

点击可编辑章节时打开该文档并切回“正文”，再次进入“项目”时恢复原分段、展开节点和滚动位置。图片、JSON 等非正文文件留在“项目”内以全屏预览呈现，不错误进入正文编辑器。

项目工作面在普通浏览状态不启用拖拽：点击打开对象，行尾菜单提供新建、重命名、复制、移动、引用和删除，长按只打开同一菜单。大纲排序必须由用户明确进入排序状态后才显示拖拽手柄；原始文件跨目录移动使用目标选择面板，避免滚动或展开树节点时误改结构。

## Status

accepted

## Considered Options

- 只提供原始文件树：完整且接近磁盘，但不能优先表达作品的卷章结构和创作进度。
- 把大纲与文件分成一级入口：两者直达，但会挤占有限的移动一级导航。
- 创作结构优先的项目工作面：默认符合创作者心智，同时通过分段保留文件和搜索能力。
