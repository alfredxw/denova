# 修改历史故事回合必须创建新分支

移动端允许用户在独立全屏编辑器中修订不存在后续依赖的当前最新回合，并保留修订记录。当目标回合之后已经存在其他故事回合时，任何内容修改都必须先明确创建新故事分支，再在新分支中编辑；原分支及其全部后续回合保持不变。

故事回合菜单必须区分“编辑当前回合”和“从此处创建分支”。系统不能静默删除后续回合，也不能把原有后续历史继续接在已经改变的前提上；完成分支编辑后进入新分支故事舞台，原路径可从“剧情线”恢复。

## Status

accepted

## Considered Options

- 任意回合原地修改：操作直接，但可能让全部后续剧情与新前提矛盾。
- 禁止修改历史：一致性最强，但不适合创作者试玩和修正 AI 输出。
- 最新回合可修订、历史回合需分支：保留快速修正，同时保护已有故事历史。
