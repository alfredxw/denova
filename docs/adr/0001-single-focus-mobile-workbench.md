# 移动工作台采用单工作面架构

移动端保留 Denova 的完整创作能力，但任意时刻只呈现一个主工作面，并在切换后保留原工作状态。我们不再追求桌面端多面板同屏：手机的可用宽高不足以同时容纳编辑器、Agent、项目树和一级导航，固定分屏会持续压缩当前任务；移动端也不降级为只读伴侣，因为完整创作流程与游戏交互仍是产品目标。

写作模式与游戏模式分别保存自己的模式工作状态。用户显式切换模式后，应恢复该模式上次的主工作面、未提交输入、当前对象、滚动位置和展开状态；只有用户明确关闭项目、退出故事或执行重置时才清除对应状态。

## Status

accepted

## Considered Options

- 桌面工作台缩小版：保留多面板同屏，但核心内容和输入区域会互相争抢空间。
- 移动伴侣：只保留浏览、审阅或轻量输入，但无法覆盖完整创作流程。
- 单工作面移动工作台：能力完整，任务单焦点呈现，切换时保留状态。
