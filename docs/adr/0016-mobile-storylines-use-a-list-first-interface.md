# 手机剧情线以纵向列表为默认界面

移动端“剧情线”默认使用纵向列表管理故事分支，而不是要求用户在二维节点画布中平移和缩放。列表将当前分支置顶，并为每条分支显示名称、分歧回合、父分支、最新摘要、回合数和更新时间；进入分支详情后，以纵向时间线查看关键回合并执行切换、重命名、继续游玩或删除。

节点关系图保留为次级“关系总览”，用于理解复杂分歧；平板、横屏或宽屏可以直接使用图形视图。手机日常流程不能依赖小地图或“重新居中”操作才能定位当前分支。

## Status

accepted

## Considered Options

- 只保留节点图：关系表达强，但手机导航和精确操作成本高。
- 完全删除节点图：日常操作简单，但复杂分支关系失去全局视角。
- 列表优先、图形辅助：分别优化管理效率和关系理解。
