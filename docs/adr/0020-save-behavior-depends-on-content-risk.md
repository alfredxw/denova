# 移动编辑按内容风险采用不同保存契约

Denova 不对所有移动编辑页面强制同一种保存方式。正文、世界资料等创作内容持续自动保存草稿，并明确显示保存中、已保存或冲突；语言、主题和字体等即时偏好修改后自动保存并生效；Agents、Skills、自动化、模型配置和导演规则等可执行配置只编辑本地草稿，通过完整校验并由用户明确保存后才生效。

可执行配置存在未保存修改时，返回操作必须提供继续编辑或放弃修改，不能静默应用半成品或丢失草稿。各模块可以复用同一保存状态与冲突组件，但不能为了界面一致而抹平不同数据的风险边界。

## Status

accepted

## Considered Options

- 全部自动保存：操作轻，但结构化配置可能在不完整或无效状态下生效。
- 全部显式保存：规则简单，但长篇创作和即时偏好增加不必要的丢失风险与操作负担。
- 按内容风险划分：契约更多，但每类数据获得符合其失败代价的行为。
