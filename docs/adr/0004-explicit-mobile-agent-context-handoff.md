# 移动端 Agent 只通过显式交接接收创作上下文

在正文与 Agent 主工作面之间普通切换时，不自动附加当前文档或选区，只恢复原 Agent 会话。用户通过“询问 Agent”“讨论本章”等明确动作发起上下文交接；交接内容在发送前以可移除条目展示来源、用途和大小，并遵守配置的上下文上限。返回正文后恢复原文档工作状态。

## Status

accepted

## Considered Options

- 自动附加当前文档：操作步骤少，但用户无法确定 Agent 实际看到了什么，并可能无意注入大段内容。
- 切换后由 Agent 自行读取：界面简单，但上下文来源、范围和成本不可预测。
- 显式上下文交接：多一个明确动作，但来源透明、大小有界，也能区分单纯查看会话与请求协作。
