# 移动故事舞台采用互动叙事阅读结构

移动故事舞台以故事回合组织内容，而不是复制 Agent 聊天气泡。AI 叙事使用全宽阅读排版；角色对白保留说话者与可用的头像或立绘；玩家输入呈现为紧凑、可辨识的行动块；检定、状态变化和工具过程收纳为可展开事件卡。

场景图像按内容宽度清晰展示并支持全屏查看，可选行动以整行选项放在自由输入区域上方。自由输入始终保留，流式生成必须维持稳定布局，不能让已呈现正文、操作按钮或输入区域持续跳动。

行动建议不是即时执行按钮。移动端最多直接显示三项，其余收纳到“更多选择”；点击建议只把内容填入自由输入框并收起列表，玩家可以修改或删除，必须再次明确发送才创建故事回合。流式生成期间保留输入草稿但禁止重复提交。

## Status

accepted

## Considered Options

- 聊天气泡：交互熟悉，但会把叙事降格为普通对话，也不适合长段阅读与系统事件。
- 纯小说阅读：沉浸感强，但玩家行动、选择和规则结果缺少清晰边界。
- 叙事阅读器加行动块：兼顾长文本阅读、玩家参与和游戏状态可解释性。
