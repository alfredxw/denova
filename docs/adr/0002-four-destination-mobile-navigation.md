# 移动端每个模式使用四入口一级导航

移动端一级导航固定为四个始终显示文字的底部入口。写作模式使用“正文、项目、Agent、更多”，游戏模式使用“故事、剧情线、资料、更多”；版本、Skills、Agents、自动化和设置等低频或共享能力收纳在“更多”中。共享能力打开时保留用户当前模式，关闭后返回原模式，不允许通过共享入口隐式切换写作或游戏模式。

写作与游戏的模式切换只放在“更多”面板顶部，以明确的分段控件呈现。移动顶部栏不常驻模式开关，只承载当前工作面标题和上下文操作，避免把全局导航、项目切换和页面操作再次挤入同一行。

移动顶部栏以当前工作对象为主标题，以当前书籍或项目为可点击副标题；进入详情层级时显示返回操作，右侧最多保留两个当前工作面的高频操作，其余收纳到溢出菜单。品牌图标、全局搜索、通知和模式切换不作为常驻顶部栏元素。

“更多”入口聚合全局后台任务状态。仅等待用户和失败任务计入数字徽标；无需处理的运行任务使用低干扰运行指示。打开“更多”后，模式切换分段下方首先显示任务中心摘要，点击进入完整任务中心，不在移动顶部栏恢复独立通知入口。

“更多”本身使用分组列表式底部面板，不使用图标九宫格：依次呈现模式切换、任务中心摘要、版本与 Skills、Agents、自动化等项目能力，以及设置等应用能力。点击条目进入独立全屏工作面，返回时回到“更多”，关闭“更多”后恢复原创作模式和主工作面；可用高度不足时面板自适应为全屏滚动布局。

移动顶部栏不常驻全局搜索或命令按钮。项目内容搜索进入“项目 → 搜索”，列表搜索由具体管理工作面提供；“更多”保留“快速操作”条目以打开命令面板，接入硬件键盘时继续支持全局快捷键。

## Status

accepted

## Considered Options

- 平铺全部一级能力：入口可直接访问，但九个以上无文字图标无法识别，也没有稳定触控空间。
- 单一菜单：界面最干净，但正文、故事和 Agent 等高频任务每次都要经过二级入口。
- 每模式四入口：保留高频直达，其余能力通过“更多”完整可达，并维持清晰的模式边界。
