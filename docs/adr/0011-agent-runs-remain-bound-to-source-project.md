# Agent 运行绑定来源项目但不阻止项目切换

Agent 运行严格归属于发起它的创作项目、Agent 会话和变更审阅边界，但不会阻止用户切换到其他项目。项目切换前必须可靠提交当前可保存内容；提交失败时留在当前项目并明确报错。离开后原项目运行继续，目标项目只展示自己的会话、上下文、文件变更和待审阅状态。

跨项目运行必须在全局状态入口中显示来源项目。用户打开该运行时，系统先保存当前工作现场，再切换到来源项目和对应会话；任何运行结果都不能注入当前项目或以缺少项目来源的通知呈现。

## Status

accepted

## Considered Options

- 运行期间禁止切换项目：隔离简单，但长时间任务会锁住整个产品。
- 切换项目时取消运行：避免跨项目恢复，但浪费已执行工作并违背明确停止原则。
- 来源项目绑定的后台运行：需要全局状态入口与可靠恢复，但兼顾隔离和持续创作。
