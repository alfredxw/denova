# 写作与游戏模式共享同一视觉外壳

写作与游戏模式在移动端共享纯白或近黑的应用背景、顶部栏、底部导航、间距、返回行为和语义状态颜色，显式切换模式不会自动切换主题或改变导航规则。红、黄、绿等强调色只承担危险、等待、成功等稳定语义，不用渐变、氛围光斑或大面积装饰制造独立游戏主题。

游戏模式的表现力来自可检查的场景图像、角色头像、故事排版、状态和检定内容。故事舞台可以比写作编辑器更具叙事感，但导演台、资料和任务中心继续保持安静、易扫描的工具界面，不能让两个模式看起来像两套产品。

## Status

accepted

## Considered Options

- 游戏模式使用独立主题：区分强烈，但共享功能、模式切换和长期维护会出现两套视觉语言。
- 全部界面严格同质：一致性最高，但故事舞台无法利用真实视觉资产增强体验。
- 共享外壳、内容差异化：保持产品统一，同时让互动叙事通过内容获得表现力。
