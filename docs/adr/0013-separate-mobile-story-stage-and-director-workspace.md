# 移动游戏模式分离故事舞台与导演台

移动端游戏模式的“故事”一级入口默认呈现面向玩家体验和创作者试玩的故事舞台，只承载故事内容、角色发言、场景图像、选择结果、行动建议与自由输入。角色状态、检定细节和上下文来源按需展开，导演计划、规则执行和事件卡不作为常驻侧栏或并排面板。

创作者通过故事舞台顶部的明确入口进入独立全屏导演台，完成后返回原故事轮次、滚动位置和输入草稿。四入口一级导航默认保留，只在软键盘打开或用户明确进入沉浸阅读时隐藏。

## Status

accepted

## Considered Options

- 故事与导演信息同屏：状态全面，但手机内容区会被控制面板持续压缩。
- 仅保留玩家故事：体验简洁，但削弱创作与调试游戏的核心能力。
- 故事舞台与导演台分离：通过明确切换同时服务试玩和创作控制。
