# 移动重写不保留旧布局兼容模式

新的移动信息架构直接替换旧版九图标底栏、项目与 Agent 抽屉、编辑器与 Agent 底部 Dock，以及相关边缘手势。产品不提供旧版布局开关、Agent 呈现方式三选一或四入口任意重排；设置只保留字体、动效、内容密度和场景图像策略等具有长期用户价值的偏好。

桌面布局不因本次移动重写而自动改变。由于项目仍处于 Beta，可以优先统一实现边界，但发布说明必须明确列出导航、Agent、可见 Tab 和手势等不兼容变化；临时开发开关不能演变成长期用户配置。

## Status

accepted

## Considered Options

- 永久保留旧布局：用户可回退，但导航、状态和测试矩阵长期翻倍。
- 开放每项布局自由组合：看似灵活，但会产生大量未经整体设计的交互组合。
- 直接替换并说明不兼容：迁移更明确，也能让新移动架构保持单一、可维护。
