# 移动 PWA 支持安全断线恢复而非完整离线模式

移动 PWA 在短时断线或系统挂起期间允许继续编辑已经打开的正文和输入草稿，并把内容作为绑定创作项目与基础版本的待同步草稿持久保存在本机。界面明确显示“离线，等待同步”；恢复连接后进行版本校验，远端已变化时进入冲突审阅，不能直接覆盖。

断线时不允许提交 Agent 或故事回合、控制后台任务、切换创作项目、执行结构迁移，或打开尚未缓存的内容。产品与安装文案不宣称完整离线创作，避免暗示浏览器拥有后端工作区的完整副本。

## Status

accepted

## Considered Options

- 不支持断线编辑：实现直接，但移动网络波动会导致真实内容丢失风险。
- 完整离线工作区：体验能力最强，但同步、冲突、任务与安全边界大幅扩大。
- 安全断线恢复：保护当前创作现场，同时保持需要后端的能力边界诚实可见。
