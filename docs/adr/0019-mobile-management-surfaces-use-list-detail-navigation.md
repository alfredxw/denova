# 移动管理功能统一使用列表到全屏详情导航

设置、Skills、Agents、自动化、版本及其他复杂管理功能在移动端统一以可搜索列表为入口，点击条目后进入独立全屏详情、编辑或日志工作面。返回列表时恢复筛选、滚动位置和选中项；桌面的多栏布局、侧边详情和横向表格不能直接压缩到手机宽度。

表格内容在手机上转换为语义完整的行或卡片，不把横向滚动作为主要阅读方式。新建、编辑、运行日志和版本 Diff 使用清晰的嵌套全屏层级；平板或宽屏达到可用空间后可以自适应恢复双栏，但不能因此改变任务含义或导航结果。

## Status

accepted

## Considered Options

- 每项功能自行适配：局部自由，但用户需要学习多套移动导航，组件行为也会持续分裂。
- 缩小桌面多栏：复用直接，但信息密度、触控和返回关系不适合手机。
- 统一列表到全屏详情：建立稳定移动模式，同时允许宽屏渐进增强。
