# 产品行为跨设备统一而界面呈现自适应

创作项目边界、Agent 运行生命周期、统一任务中心、显式上下文交接、保存契约、故事分支和状态修订等产品行为在手机、平板和桌面保持一致。它们不能只在移动端成立，否则同一项目从不同设备访问时会产生不同数据语义和恢复结果。

四入口底栏、单主工作面、隐藏可见 Tab 栏、专注输入态、列表优先剧情线和全屏详情等属于移动呈现。桌面可以继续使用多栏、可见 Tab 和并排审阅，但必须消费相同项目、任务、上下文和历史模型。

## Status

accepted

## Considered Options

- 移动端独立产品行为：便于局部重写，但同一数据在设备间会出现不一致语义。
- 所有设备使用同一布局：实现表面统一，但无法发挥不同屏幕与输入设备的优势。
- 行为统一、呈现自适应：保持领域边界稳定，同时为各设备优化交互。
