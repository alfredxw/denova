# 移动端以单文档编辑器替代可见 Tab 栏

移动端正文工作面一次只显示一个文档，不呈现桌面式多 Tab 栏。点击顶部文档标题可通过“最近打开”面板快速切换文档，完整目录树由“项目”一级入口承载；每个已打开文档分别保留草稿、光标、选区、滚动位置和撤销历史，未保存状态显示在当前标题附近。

## Status

accepted

## Considered Options

- 保留横向 Tab 栏：直接复用桌面心智，但标题空间不足、关闭操作拥挤，并持续占用编辑高度。
- 左右滑动切换文档：界面简洁，但会与文本选择、编辑器手势和系统边缘手势冲突。
- 单文档呈现加文档切换面板：保留多文档能力与状态，同时让当前正文获得完整宽度。
