# Agent 运行不依赖移动工作面保持打开

用户离开 Agent 工作面进入正文或项目时，当前 Agent 运行继续执行，不因组件隐藏、路由变化或前端流式连接变化而取消。Agent 一级入口持续表达运行中、已完成、失败或等待用户输入等状态；完成和错误不能只通过短暂提示传达，也不会自动抢回用户当前工作面。

返回对应 Agent 会话时，应从后端持久状态恢复消息、工具执行结果和运行进度。PWA 被系统挂起或网络重连后同样续接已有运行；只有用户明确停止时才终止，不使用写死的执行超时。

## Status

accepted

## Considered Options

- 离开 Agent 就取消：生命周期简单，但会把长时间 LLM 运行变成导航陷阱。
- 运行时禁止导航：避免状态同步，但阻止用户在等待期间继续创作。
- 运行独立于工作面：需要持久状态和恢复机制，但符合长期 Agent 任务与移动设备挂起行为。
