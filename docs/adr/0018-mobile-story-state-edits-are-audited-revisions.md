# 移动端当前状态默认只读并通过修订修改

移动端当前状态列表和卡片默认只读，服务快速查看、筛选和定位。创作者明确进入单个角色或状态记录的全屏编辑工作面后才能修改；保存前展示字段变化摘要，保存时创建状态修订，记录来源、时间、所属故事分支和基准故事回合，并支持撤销或恢复。

状态修订只影响目标故事分支，不反向改写世界资料，也不能无记录覆盖原状态。批量修改通过独立流程发起，普通列表不铺设大量输入框，以避免滚动、失焦或触控误操作改变未来剧情上下文。

## Status

accepted

## Considered Options

- 卡片内直接编辑：步骤最少，但误触、保存边界和变更来源难以判断。
- 完全禁止手动修改：数据最稳定，但不满足创作者调试和纠错需求。
- 显式状态修订：多一步进入和确认，但兼顾可控干预与历史可追踪性。
