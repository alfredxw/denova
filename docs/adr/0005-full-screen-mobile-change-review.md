# 移动端变更审阅使用独立全屏工作面

Agent 修改文件后，消息中只展示修改文件、增删规模和待审阅状态的摘要卡；用户明确打开后进入独立全屏变更审阅，完成或返回时回到原 Agent 会话。移动端按文件使用单栏统一 Diff，不同时呈现正文、Agent 与 Diff；审阅反馈作为来源明确、大小有界的上下文交回 Agent。

正文和 Agent 一级入口可以显示待审阅数量，但新变更不会自动打断用户或切换工作面。接受、撤销和继续修改都从变更审阅发起。

## Status

accepted

## Considered Options

- 在 Agent 消息中展开完整 Diff：进入成本低，但长 Diff 会破坏对话阅读和滚动定位。
- 在正文旁并排审阅：接近桌面体验，但违背移动端单工作面原则。
- 独立全屏审阅：多一次显式进入，但能提供完整、稳定且可返回的审阅流程。
