# 游戏资料工作面分离当前状态与世界资料

移动游戏模式的“资料”工作面只提供“当前状态”和“世界资料”两个明确分段。当前状态属于选定故事分支，呈现随故事回合变化的角色属性、资源、关系、伤势和世界变化；世界资料属于创作项目，呈现跨故事分支持续有效的角色、地点、势力、物品和规则等稳定设定。

“资料”默认打开与当前游玩最相关的当前状态，并记住用户上次分段。导演目标、事件卡、检定配置和叙事预设归属于导演台或“更多”；故事回合继续作为历史事实来源，不复制成第二套可编辑历史。

## Status

accepted

## Considered Options

- 合并状态与资料：入口少，但运行时变化和稳定设定会互相污染。
- 分成两个一级入口：边界直观，但挤占移动底部导航。
- 在资料工作面内分段：保持一个一级入口，同时明确作用域与变化速度。
