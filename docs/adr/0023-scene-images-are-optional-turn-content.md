# 场景图像作为可选的回合级正式内容

移动故事舞台在场景图像存在时，将其作为对应场景或故事回合的全宽正式内容展示，使用稳定宽高比预留空间并支持全屏查看。正文不覆盖在图像上，图像不作为暗化或模糊的整页背景；没有图像时保持完整纯文本体验，不绘制无意义渐变占位。

图像生成属于可恢复后台任务，不阻塞故事阅读或后续操作。系统默认不强制每回合生成，生成时机和频率由故事或创作项目图像配置决定，并明确其默认值与持久化作用域。

## Status

accepted

## Considered Options

- 图像作为页面背景：沉浸感直接，但文字可读性、裁切和真实内容检查都会受损。
- 每回合强制生成：视觉连续，但成本与等待时间会主导故事节奏。
- 可选回合内容：图像真正参与叙事，同时保留纯文本速度与用户控制。
