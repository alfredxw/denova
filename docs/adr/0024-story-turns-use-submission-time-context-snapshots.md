# 故事回合使用提交时锁定的上下文快照

玩家提交行动时，系统为该故事回合锁定一份记录来源、用途、版本和大小的回合上下文快照。正在生成的回合只使用该快照；生成期间创作者可以继续编辑导演计划、规则和状态，但保存结果明确标记为从下一回合生效，不会中途改变当前模型输入。

若用户需要让新配置影响当前回合，必须明确停止并重新生成。系统不能静默重启运行或在同一回合混合新旧配置；回合审计应能查看当时使用的导演计划、规则、状态和其他上下文版本。

## Status

accepted

## Considered Options

- 运行中动态读取最新配置：编辑即时生效，但同一次生成的输入边界无法解释或复现。
- 生成期间锁定全部编辑：一致性简单，但长运行会阻塞创作者工作。
- 提交时快照、后续生效：允许并行编辑，并保持每个回合可审计和可复现。
