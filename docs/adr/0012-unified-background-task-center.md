# 长时间运行统一进入任务中心

Denova 将能够脱离当前工作面继续执行的 Agent、自动化、图像生成、批量导入导出及未来同类流程统一建模为后台任务，并通过跨创作项目的任务中心呈现。任务至少具有来源项目、任务类型、运行状态、开始时间和可恢复目标，状态使用运行中、等待用户、失败和已完成等可行动语义。

普通提示、保存成功、版本更新和短暂前端加载不属于后台任务，不能为了统一入口而塞进任务中心。任务中心也不替代具体工作面的完整日志、Agent 消息或变更审阅，只负责发现状态和恢复到正确现场。

移动端通过“更多”一级入口聚合任务状态：等待用户和失败任务计入数字徽标，运行中但无需处理的任务只显示低干扰指示。“更多”面板在模式切换控件之后首先展示任务摘要，并可进入全屏任务中心；移动顶部栏不另设通知铃铛。

## Status

accepted

## Considered Options

- 每项功能维护独立运行入口：实现局部直接，但跨项目状态、徽标和恢复行为会持续分裂。
- 把全部通知统一为消息中心：入口单一，但不可行动信息会淹没真正需要处理的长任务。
- 统一后台任务中心：要求稳定任务协议，但能服务现有和未来的长时间创作流程。
